# PocketVR Gun — เกม FPS ยิงมอนสเตอร์ (แยกโปรเจกต์ ไว้รวมกับ PocketVR ทีหลัง)

เกมยิงปืนมุมมองบุคคลที่หนึ่ง เล่นใน VR Box ด้วย **ปืนกลยาว** ศัตรูเดินเข้าหาตัวผู้เล่น (zombie, runner, drone ที่ลอย, tank, บอสทุกรอบที่ 5) ยิงหัวได้ดาเมจ x2
มี 2 โหมด:
- **โหมดหัว** (ใช้ได้เลยในแอปเดี่ยวนี้): เล็งด้วยการหันหัว ยิงด้วยการแตะ/ปุ่ม
- **โหมดมือ** (ต้องมี hand tracking สองมือ = ทดสอบได้เมื่อรวมกับ PocketVR): ดูหัวข้อด้านล่าง

## โหมดมือ (`world.handMode = true` + host เรียก `hands()` ทุกเฟรม)
| ท่า | ผล |
|---|---|
| ปืนกลลอยติดตัวเรา (ล่างขวา ตามตัวเรา หมุนตามหัวช้า ๆ) — ก้มมองหาแล้ว **กำมือที่ปืน** | ปืนเข้ามือ |
| มือที่ถือปืน | ปืนชี้ตามที่มือถูกมองเห็นจากตา (มือ = crosshair) |
| **หุบนิ้วชี้ / ชูนิ้วชี้ ของมืออีกข้าง** | หุบ = ยิง (ปืนกลยิงรัวตราบที่หุบ), ชู = หยุด/พร้อม |
| **แบมือ** มือที่ถือปืนค้างครึ่งวินาที | วางปืน (บินกลับไปติดตัว) |
| **แบมือยื่นไปข้างหน้า** (ตอนไม่ได้ถือปืนเท่านั้น) | เดิน ไปทางที่มือยื่นไป ยิ่งยื่นไกลยิ่งเร็ว ขอบจอมืดตอนเดินกันเมา |
| มือที่ถือปืนหลุดจากภาพ | ปืนยังอยู่ในมือแต่เล็งด้วยหัวชั่วคราว |

ค่าที่ปรับได้อยู่ใน `NvGunHands` (ตำแหน่งปืนที่ตัว, ระยะ/มุมที่หยิบได้, ระยะแขนที่เริ่มเดิน, ความเร็วสูงสุด, เวลากำ/แบม ฯลฯ)

## เล่นยังไง
| ทำ | ผล |
|---|---|
| แตะ / ค้าง | ยิง (แตะที่หน้าเริ่ม/แพ้ = เริ่มเกม) |
| แตะ 2 นิ้ว / ปุ่มลดเสียง | รีโหลด (รีโหลดอัตโนมัติเมื่อกระสุนหมด) |
| ปุ่มเพิ่มเสียง | สลับปืนพก ↔ ไรเฟิล (ปลดล็อกรอบที่ 2) |
| แตะ 3 นิ้ว | สลับภาพเดี่ยว ↔ ภาพแยกซ้ายขวา (VR Box) |
| จอยบลูทูธ | A/R1/R2 ยิง, X รีโหลด, Y เปลี่ยนปืน |

## Build
1. เอาทั้งโฟลเดอร์ขึ้น GitHub (branch `main`) → Actions จะรันเทสต์กฎเกม, build APK แล้วออกเป็น Release (`PocketVRGun.apk`) เหมือน PocketVR
2. ทดสอบกฎเกมในเครื่องที่มี JDK: `sh test/run.sh` (ไม่ต้องมี Android)

## โครงสร้าง (ออกแบบให้ย้ายเข้า PocketVR ได้ตรง ๆ)
```
app/src/main/java/com/pocketvr/app/     <- แพ็กเกจเดียวกับ PocketVR: ก๊อปไปวางได้เลย ไม่ต้องเปลี่ยนชื่อ
  NvGameWorld.java   รอยต่อ (interface) ระหว่างเกม 3D กับ renderer
  NvGunCore.java     กฎเกมล้วน ๆ (Java ล้วน ไม่มี Android): คลื่นศัตรู (วิ่งเข้าหาผู้เล่นตรงไหนก็ตาม), hit-scan, กระสุน, รีโหลด, คะแนน
  NvGunHands.java    ตรรกะมือล้วน ๆ (Java ล้วน): หยิบ/วางปืน, เล็ง, ไกด้วยนิ้วชี้, เดินด้วยมือ
  NvGunWorld.java    วาดศัตรู/ปืน/เอฟเฟกต์/crosshair + รัน core ทุกเฟรม
  NvGunHud.java      แผงตัวเลข (HP, กระสุน, คะแนน) เป็น Bitmap
  NvGunGfx.java      สำเนาของ Nv3D (ตอนรวมจะลบแล้วใช้ Nv3D แทนได้)
app/src/main/java/com/pocketvr/gundemo/ <- ส่วน host สำหรับเล่นเดี่ยว (ทิ้งได้ตอนรวม)
  GunActivity / GunRenderer / GunSound
test/NvGunCoreTest.java                 <- เทสต์กฎเกม 29 ข้อ
test/NvGunHandsTest.java                <- เทสต์ตรรกะมือ 32 ข้อ (ใช้มือสังเคราะห์ ไม่ต้องมีกล้อง)
MERGE.md                                <- ขั้นตอนรวมเข้า PocketVR
```
`NvGunCore` ไม่รู้จักกล้อง/จอ/มือ มันรับแค่ "ตาอยู่ไหน, เล็งไปทางไหน, ไกถูกกดไหม" ต่อเฟรม
`NvGunHands` แปลงจุด 21 จุดของมือ (รูปแบบเดียวกับที่โมเดลมือของ PocketVR ให้) เป็น "ถือปืนอยู่ไหม, เล็งทางไหน, ไกกดไหม, เดินเร็วเท่าไร"
ดังนั้นเปลี่ยนวิธีควบคุมได้โดยไม่แตะกฎเกม

## ปรับความรู้สึกเกม (ใน `NvGunCore`)
`assistDeg` (ตัวช่วยเล็ง, ค่าเริ่ม 1.6°), `W_DMG/W_COOL/W_MAG/W_RELOAD` (ปืน), `spawn()` (HP/ความเร็ว/ขนาดศัตรู), `nextWave()` (จำนวนศัตรูต่อรอบ)

## สิ่งที่ยังไม่ได้ยืนยัน (ต้องลองบนเครื่องจริง)
- โค้ด Android คอมไพล์ผ่านกับ stub เท่านั้น (ไม่มี Android SDK ในเครื่องที่เขียน); กฎเกมและตรรกะมือผ่านเทสต์จริงบน JVM
- **ตรรกะมือพิสูจน์แล้วกับมือสังเคราะห์เท่านั้น** ยังไม่เคยเห็นมือจริง: เกณฑ์ "นิ้วยื่น/หุบ" (`EXT`/`CURL`), ขนาดฝ่ามือที่ใช้ประมาณระยะ, ตำแหน่งปืนที่ตัว ต้องจูนกับมือจริง
- การเล็งด้วยมือจะหน่วง/สั่นกว่าหัว (โมเดลมือ ~10 ครั้ง/วินาที) จึงตั้งตัวช่วยเล็งไว้ 3.5° ในโหมดมือ
- การแมปแกนเซ็นเซอร์ตอนจอแนวนอน (ถ้าหันซ้ายแล้วภาพไปขวา ให้ดู `GunActivity.onSensorChanged`)
- ภาพ VR ยังไม่มี lens distortion; เสียงเป็นเสียงสังเคราะห์ ยังไม่ได้ฟังจริง
